# Hyperliquid Scanner V3.3 — GitHub Pages V21

## Modifications V21
- Le panneau **📱 Diagnostic connexion** est maintenant placé immédiatement sous **🧾 Journal d’activité & erreurs**.
- Les horloges du gagnant sont agrandies et espacées pour utiliser beaucoup mieux la largeur disponible.
- Les horloges du classement sont également agrandies et réparties sur toute la largeur de leur cellule.
- Le panneau de durée reste centré entre les deux horloges.
- Les nombres 1–12 restent proches des graduations.
- AM/PM est centré dans le cadran.
- Correction du positionnement des heures de début/fin sous le graphique : chaque libellé est centré sur sa ligne verticale verte lorsqu’il n’y a pas de chevauchement. Un déplacement n’est effectué qu’en cas de chevauchement, avec une liaison explicite vers la graduation correspondante.

## Déploiement
Déposer `index.html` à la racine d'un dépôt GitHub Pages et utiliser le workflow GitHub Pages de la version précédente.
