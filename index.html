📌 Mode fichier local détecté
La connexion à l'API se fait en direct (sans proxy). Si elle échoue à cause des restrictions CORS du navigateur, servez le fichier via un serveur local :
  • 1. Ouvrez un terminal dans le dossier du fichier
  • 2. Exécutez : python3 -m http.server 8000 (ou py -m http.server 8000 sur Windows)
  • 3. Ouvrez http://localhost:8000 dans votre navigateur
💡 Alternative : utilisez la version en ligne sur GitHub Pages.
